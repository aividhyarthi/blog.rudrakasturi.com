**Short answer:** Bing has been observed testing a separately labelled AI-Generated answer card inside search results. Reports describe it on Android, mobile browsers and desktop, but Microsoft has not confirmed a wider rollout or explained how the feature selects sources.

Microsoft Bing appears to be testing another way to show AI-generated information inside search results. The new format is a standalone card labelled "AI-Generated answer", separate from the regular list of web links.

The test was first spotted on Android and reported by Search Engine Watch on November 23. Search Engine Roundtable reported it on November 24 and said it was able to reproduce the card on both mobile and desktop.

Microsoft has not publicly explained the test or confirmed that it is being rolled out widely. For now, this should be treated as an observed experiment, not a permanent change to Bing Search.

## What does the new Bing answer card look like?

The card carries an explicit "AI-Generated answer" label and provides a generated response within the search results page.

The wording reported by Search Engine Roundtable says the summary was generated using AI based on multiple online sources. It also directs users to "Learn more" links to view original source information.

Search Engine Watch first observed the card while searching for a Minecraft world seed query in the Bing Android app and mobile browsers. The card included a heading, numbered steps and a "See more" option to expand the response.

Search Engine Roundtable later reported that it could reproduce the test on mobile and desktop. The difference between these observations is another reason not to assume that every user sees the same interface.

## Is this the same as Copilot Search or Bing's other AI answers?

The reports describe this as a separate presentation from Bing's existing Copilot Search and AI answer experiences.

That distinction matters. Search engines can test more than one way to generate and display an answer. A card embedded in the normal results page is not necessarily the same product or interface as a dedicated conversational search experience.

Microsoft has not yet explained how this card is generated, which sources it uses, how it decides when to appear or whether it will become a permanent feature. We should not fill those gaps with assumptions.

## Why should publishers and SEO teams pay attention?

A standalone answer card can occupy space that would otherwise be used by traditional search listings. If the format expands, it may change how people scan the results page and whether they open a website for a basic answer.

But one test is not enough to conclude that Bing organic clicks are falling. The current reports do not provide impression data, click-through rates, rollout percentages or publisher traffic impact.

For now, the practical question is whether the card appears for queries that matter to your business and whether it links to the sources it uses.

## What should SEO teams check?

1. **Test important query groups.** Check branded, non-branded, informational, local and product queries in Bing on mobile and desktop.
2. **Record the result layout.** Save the date, device, query, country and whether the AI-generated card appears.
3. **Check the source links.** Open the "Learn more" links and record the exact URLs shown.
4. **Compare with Copilot Search.** Do not combine this card with citations from a separate Copilot experience.
5. **Monitor Bing Webmaster Tools.** Track search impressions, clicks and query changes over time. Where available, keep AI-related reporting separate from ordinary web search.
6. **Repeat the test.** A one-time observation can be a limited experiment or a personalised result. Use the same query set and devices for comparisons.

## The bigger picture

Google, Microsoft and other search platforms are experimenting with different ways to place generated answers alongside the web. The label, layout and source links matter because users need to understand where an answer came from and how to verify it.

For publishers, the sensible response is to observe the test, record the queries where it appears and measure actual changes before making strategic decisions.

Bing's new card is worth watching. It is not yet evidence of a permanent search redesign or a measurable traffic decline.
