OpenAI has added a Learn more link to single-image ChatGPT advertisements. The link appears below the ad description and opens the destination URL already configured in Ads Manager. According to the November 25 advertiser update, no additional setup is required.

This raises a practical question for advertisers: can the label be changed to Call now, Book now, Shop now or Sign up?

**As of November 26, 2026, OpenAI's public self-serve documentation does not describe a general setting to replace the default Learn more label on single-image ads.** It would therefore be unsafe to promise that every advertiser can customise it.

There is also a difference between a previous limited test of dynamic CTA labels reported in May and the current documented default Learn more link. A test or mock-up is not proof that the option is generally available today.

## What does the new Learn more link do?

It is a clickable action below the ad description. It sends the user to the landing page already selected for that ad in Ads Manager.

The advertiser does not need to create a second URL just for the CTA. The most important setup decision is therefore choosing a destination that matches the promise made in the headline and description.

## Can you change it to Call now, Sign up or Book now?

The current public OpenAI guide says Learn more is the only CTA option for multi-image ads. For single-image ads, OpenAI's help page describes the Learn more link but does not publish a menu of alternative labels or a setting for custom CTA text.

| Ad format | What public guidance currently confirms |
|---|---|
| Single image | Learn more link appears by default and opens the configured landing page |
| Multiple images | Learn more is the only documented CTA option; images and CTA open the same URL |
| Custom CTA such as Call now or Sign up | No general self-serve control documented in the public guide reviewed |

If an account shows a different option, treat it as an account-specific test or rollout and confirm it in the Ads Manager interface or with OpenAI support.

## How to set up the destination correctly

Even when the visible CTA label cannot be changed, advertisers can make the next step clear.

### Step 1: Open Ads Manager

Sign in to the ChatGPT Ads account and open the campaign and ad you want to edit.

### Step 2: Review the destination URL

Open the ad details and check the landing page URL. Make sure it is the page that best matches the ad's offer.

### Step 3: Match the page to the intended action

- For a phone enquiry, use a page with a clearly visible phone number and a working mobile tap-to-call link.
- For a booking, use a booking page with available dates and a clear reservation process.
- For a registration, use the relevant sign-up form.
- For a product sale, use the exact product or collection page.
- For a consultation, use a page that explains the service and provides a clear enquiry or booking route.

### Step 4: Add tracking parameters

Add suitable UTM parameters to the destination URL so analytics tools can identify traffic from ChatGPT Ads. Keep naming consistent across campaigns and ad groups.

### Step 5: Test the full journey

Open the destination on desktop and mobile. Check that the page loads, the form works, the phone link is clickable and the page does not introduce a different offer from the advertisement.

## Can the headline and description carry the action?

Yes. The headline and description can explain the next step even when the CTA label remains Learn more.

For example:

| Business goal | Example headline | Example description | Landing page |
|---|---|---|---|
| Phone enquiry | Speak to a Specialist | Check service availability and contact our team | Contact page with phone number |
| Registration | Join the Free Workshop | See the agenda and reserve your place | Registration page |
| Booking | Find an Appointment | Compare available times and choose a slot | Booking page |
| Shopping | Explore the Collection | Compare styles, prices and available sizes | Product collection |

These are copy examples, not approved templates or guarantees of delivery.

## A note about the earlier dynamic CTA test

In May 2026, Digiday reported that OpenAI was testing more customisable ad experiences with CTA labels such as Shop now, Book now, Sign up and Learn more. That report described an early test on a small subset of ads. It should not be confused with the November update, which documents Learn more as the default link.

## What advertisers should do now

Do not spend time searching for a setting that OpenAI has not documented as generally available. Configure the destination page, headline, description and tracking so the user's next step is obvious.

If your account does expose alternative CTA labels, record the format, campaign type and account eligibility before relying on the option. Interface experiments can change.

**The practical rule is simple: treat Learn more as the current default, and make the landing page do the conversion work.**
