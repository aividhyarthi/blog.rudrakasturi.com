Google considers Core Web Vitals to be a set of particular elements that contribute to a webpage's overall user experience. Three specific page performance and user interaction statistics make up Core Web Vitals: greatest contentful paint, initial input delay, and cumulative layout shift. 

In a nutshell, Core Web Vitals are a subset of variables that will be included in Google's "page experience" score (essentially, how Google evaluates your website's overall user experience). To help improve user experience, Google has introduced a new collection of measurements called Core Web Vitals. The June 2021 Core Update, as Google dubbed it, was delivered last month, with a July update on the way. 

The Core Web Vitals are a set of metrics Google is developing and plans to incorporate into their overall search algorithm in May of 2021, as announced in early 2020. Given that it's nearly 2021, anyone who wants to get a jump start on optimising their website for this next algorithm change should start now. Thankfully, Google has been extremely open about what these new measures are and how they work. With that knowledge, you can create a checklist of action items to review and optimise on your site in preparation for the eventual implementation of these new ranking variables. Here are 28 items to add to that list. 

**What Is the Importance of Core Web Vitals?**

Page experience will be an official Google ranking criteria in the future and the new signals that combine ‘Core Web Vitals’ will play a significant role in that score. Based on the announcements made by the Tech Giant basic web vitals will account for the majority of your page experience score. It's crucial to note that a high page experience score won't automatically push you to the top of Google's search results. Nevertheless, Google clarified that page experience is one of the several (about 200) characteristics that they consider when ranking websites in search. 

Well, you have until next year to enhance your site's Core Web Vital ratings, according to Google. Hence, there's no reason to panic. However, if you want to raise your Core Web Vitals score before then, that's fantastic. 

**Let us to break down the Core Web Vitals for a good score:**

**_Image enhancement_**: One of the most important and influencing aspects in the core web vitals is images and pictures. Loading pictures is the most common cause of delay before a page is fully loaded. The time until some initial rendering is measured by all of the web vitals is fairly high. As a result, image optimization is often the most effective strategy for boosting fundamental web metrics. 

**_CSS optimization:_** CSS has become such an important element of many site designs that removing it renders the web nearly unrecognisable. With so much of a website depending on CSS for everything from colours to placement, it's more crucial than ever to make sure your code is efficient.

**_Optimisation of JavaScript_**: JavaScript is one of the most common causes of code bloat that variably delays the website loading process. Even if it doesn't appear to have much of an effect based on what you're doing to it, optimising your site's JS can help it speed up significantly. 

**_Video enhancement_**: Videos are becoming increasingly important for the digital marketing success of an average website. So focusing on core content to video-based advertising and everything in between should be a priority not a choice. Even with partial loading and contemporary video buffering, they're massive files that also affect the loading speed of the. Make the most of the video as much as you can.

**_Optimisation of fonts and icons_**: The use of fonts and icons can have a much greater impact on a site's load times than you might think. Optimizing them may appear to be trivial detail work, but after you see the impact, you'll wonder why you've never done it before.

**_Optimizing the server_**: It doesn't matter how many optimizations you make to your website's code, pictures, or other features; none of them will help if your server is slow. Web hosting is rapidly ageing due to the profusion of web hosting businesses and the continual development of faster and stronger technology. It may be desirable to alter or enhance every few years.

**_Further optimization_**: This is where you'll find anything that doesn't fit into another category. These extra optimizations may or may not apply to your site's design, but if they do, taking care of them can be extremely beneficial.
