**Source:** Google Search Central documentation updates on [Product Markup](https://developers.google.com/search/docs/appearance/structured-data/merchant-listing#technical-guidelines) and [Generating Structured Data with JavaScript](https://developers.google.com/search/docs/appearance/structured-data/generate-structured-data-with-javascript) - October 1st, 2023.

**Important Points To Consider From The Update:**

*   **JavaScript-generated Product Markup is supported:** Google confirms its continued support for structured data generated dynamically with JavaScript for e-commerce websites.
*   **Prioritise Initial HTML for Product Markup:** While JavaScript generation is acceptable, Google emphasises best practice is to include Product Markup directly within the initial HTML of the webpage. This ensures optimal crawling and indexing for shopping results.
*   **Prepare for Increased Server Load:** Websites utilising JavaScript for Product Markup generation are advised to ensure their servers can handle potential increases in traffic. This highlights the resource-intensive nature of JavaScript rendering on Google's end.

**Direct Quotes From Google:**

*   "We recommend putting Product markup in the initial HTML for best results..."
*   "...making sure that your server can handle increased traffic if you're generating Product markup with JavaScript."

**Impact and Action Items:**

*   **E-commerce websites should review their Product Markup implementation:** Websites should check if their current method aligns with Google's best practices.
*   **Prioritise moving Product Markup to initial HTML where possible:** This will improve visibility and performance in Google Shopping results.
*   **Ensure server capacity can handle increased demand:** This is crucial for websites reliant on JavaScript-generated Product Markup.

**Why You Should Care**?

This update reinforces Google's focus on providing the best user experience by prioritising quickly and efficiently processed content. While supporting various implementations, they clearly recommend placing Product Markup within the initial HTML for optimal search performance. E-commerce businesses should prioritise this adjustment for improved visibility and potential traffic gains.
