Perplexity has introduced Multiagent, a new effort level in Perplexity Computer that allows a lead agent to divide a large assignment among as many as 16 agents running different frontier models. The agents work at the same time, share their findings and check one another's work before returning a combined result.

The feature is positioned above Perplexity's existing Ultra effort level. It is designed for work that has several connected parts, rather than a single question that one model can answer in one pass.

Perplexity announced Multiagent on November 24, 2026, as part of a wider product update covering mobile teammates, a Chrome extension, browser control and new ways to turn repeated work into reusable skills.

## How Multiagent works

The process has three main parts.

1. **A lead agent breaks down the assignment.** It identifies the separate tasks needed to complete a larger piece of work.
2. **Specialist agents work in parallel.** Up to 16 agents can use different frontier models, investigate their assigned parts and share findings.
3. **The system combines and checks the work.** Perplexity says agents can check each other's findings before the lead agent returns one deliverable.

This is different from simply asking one chatbot to think for longer. The work is distributed across several agents, each handling part of the assignment.

Perplexity gives examples such as comparing risk factors across company filings, pressure-testing a business forecast and reviewing contracts, financial statements and customer metrics during due diligence.

## What kind of work could benefit from 16 agents?

The feature is most relevant when a task can be divided into independent but related research streams.

**Financial research:** One agent can review revenue trends, another can inspect risk disclosures, while others compare competitors and identify changes between annual filings.

**Market research:** Separate agents can examine customer segments, pricing, market size, distribution and competitor activity before the findings are brought together.

**Editorial research:** Agents could investigate different parts of a subject, collect primary sources, compare claims and prepare a structured evidence pack. An editor would still need to verify the sources and approve the final story.

**Enterprise analysis:** A team could ask agents to review contracts, financials and customer data in parallel, then assemble a risk memo. This is close to one of the use cases Perplexity itself describes.

The benefit depends on the task. A simple factual question does not need 16 agents. More agents can also mean more coordination, more model usage and more material that a human must review.

## Multiagent is part of a wider Perplexity Computer update

The November 24 announcement includes several connected changes.

### Teammates can be contacted from mobile and CarPlay

Perplexity says users can call teammates from iOS, Android and CarPlay, or manage them through the Mac app. Users can speak to a teammate, redirect ongoing work and respond when the teammate asks for a decision.

Perplexity lists availability for Max subscribers, with specific Enterprise access in beta and dependent on organisation settings.

### The Chrome extension brings Computer into the browser

The updated extension adds a side panel for Chrome and other Chromium browsers, including Edge and Brave. Computer can work with pages in the user's browser, including sites where the user is already signed in, subject to browser permissions.

This is a meaningful change because the agent can work in the user's existing browser context rather than only in a separate chat window. Site-by-site browser permissions remain important.

### Brain can turn repeated work into skills

Perplexity says Brain can create and refine personal skills from past Computer sessions and memory. The idea is to convert repeated workflows, preferences and corrections into reusable instructions.

The company says this is on by default for eligible US Max subscribers. Users can inspect and edit the generated skills in the Plugins tab, or turn automatic updates off.

### Computer gains more enterprise and developer capabilities

The same changelog also describes Cloud Desktop, financial filing citations, an Orchestrator API for access to multiple models, a Context API for extracting web content, a Monitor API for tracking topics and page changes, and connectors for agent workflows.

These are not all the same feature or available to every account. The changelog gives different availability conditions for individual capabilities.

## Who can use Multiagent?

Perplexity says Multiagent is available to Perplexity Max and Enterprise Max subscribers on web, iOS, Android and Mac. Enterprise administrators can enable it as the maximum effort level for a role in organisation settings.

This is not a general free-tier launch. Access depends on subscription and, for enterprise accounts, administrator configuration.

## What this means for the AI agent market

The announcement points to a change in how AI products are being positioned. The competition is no longer only about which model produces the best answer. It is also about which product can organise work, use tools, delegate tasks and return a verifiable result.

Perplexity is combining search, model choice, browser interaction and delegated agents in one environment. This makes the product more like a research and work platform than a conventional answer engine.

For businesses, the useful question is not whether 16 agents are better than one. It is whether splitting a task reduces completion time or improves the quality of the final work enough to justify the cost and review effort.

Our [guide to how Perplexity decides which sources to cite](/how-perplexity-decides-which-sources-to-cite/) explains the search and source-selection side of the product. Multiagent adds another layer: how the platform organises work after a user gives it a complex assignment.

## What businesses should test

1. **Choose a repeatable assignment.** Use a competitor review, annual report comparison or structured market scan.
2. **Define the evidence standard.** Require source links, dates, page references and a clear separation between facts and assumptions.
3. **Compare one agent with Multiagent.** Run the same task both ways and compare completion time, factual accuracy and coverage.
4. **Check for duplicated or conflicting work.** Parallel agents may find overlapping information or reach different conclusions.
5. **Measure the cost of review.** A faster first draft is not necessarily a faster completed task if a person must spend hours checking it.
6. **Keep approval with a person.** Do not let an agent's internal cross-check replace human verification for financial, legal, medical or editorial decisions.

A useful measure is *verified task completion rate*: the percentage of assignments that meet a defined evidence and accuracy standard without major human correction. Track it alongside time saved and cost per completed task.

## Frequently asked questions

### What is Perplexity Multiagent?

Multiagent is a new effort level in Perplexity Computer. A lead agent divides a complex assignment among up to 16 agents running different frontier models. They work in parallel and combine their findings into one result.

### Can Perplexity use 16 different AI models at once?

Perplexity says Multiagent can use up to 16 agents running on different frontier models. The announcement does not promise that every task will always use 16 agents or a fixed combination of models.

### Is Multiagent available to free Perplexity users?

Perplexity lists availability for Max and Enterprise Max subscribers on web, iOS, Android and Mac. Enterprise administrators can control access through organisation settings.

### How is Multiagent different from asking one AI model to reason longer?

A single model works through the task as one process. Multiagent divides the assignment across several agents that can investigate different parts in parallel, share findings and check one another's work.

### Does using more agents guarantee a better answer?

No. More agents can improve coverage for a complex task, but they can also add coordination overhead, cost and conflicting findings. The final result still needs to be checked.

### What else did Perplexity announce on November 24?

The update also covers mobile and CarPlay access to teammates, an updated Chrome extension, self-improving skills through Brain, Cloud Desktop improvements, model options and several developer APIs.

## The bigger shift

Multiagent is a useful signal of where AI products are heading. Instead of competing only to answer a prompt, platforms are trying to complete assignments that involve research, browser activity, analysis and coordination.

The real test will be whether these systems can deliver more reliable work at a lower total cost, including the human time needed to verify the result. That is a stronger measure than the number of agents displayed on the screen.
