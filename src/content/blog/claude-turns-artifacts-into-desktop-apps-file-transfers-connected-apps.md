Anthropic has added a new way to take Claude-created Artifacts out of the chat window. Users can now install an Artifact as a standalone app on Mac or Windows, giving it its own window and icon on the desktop.

The November 24, 2026 update also introduces file transfers through connected apps in beta and moves Claude's Monthly Recap out of beta. Together, the changes make Claude more useful as a place to create small tools, move work between applications and review activity across different Claude products.

The features are rolling out with different plan and availability conditions. They should not be treated as one universal release available to every user at once.

## Claude Artifacts can now be installed as desktop apps

Artifacts are interactive outputs that Claude creates alongside a conversation. They can include small applications, tools, visualisations and other working experiences.

Anthropic now allows users to install an Artifact as an app on a Mac or Windows computer. The installed version gets its own window and icon and opens like another desktop application.

Anthropic says an installed Artifact can interact with the operating system in ways that other apps can. The feature is currently in beta.

This is a shift in how users can work with AI-generated tools. Earlier, an Artifact was primarily something to open and use inside Claude. Installing it as an app makes it easier to return to a tool without searching through an old conversation.

It does not mean Claude has become a full desktop software development environment. The feature is an installation option for Artifacts, and the capabilities of each installed Artifact depend on what it was built to do.

## Claude can transfer files through connected apps

Anthropic has also started rolling out file transfers with connected apps in beta.

Claude can send a file to an app the user has connected, or save a file offered by that app. This extends connectors beyond simply finding information and bringing it into a Claude conversation.

The rollout is gradual. Anthropic lists Pro, Max and Ultra plans, as well as Team and Enterprise plans when an organisation owner enables the feature.

For a business user, this could reduce the steps involved in moving a report, spreadsheet or other working file between Claude and a connected service. The exact workflow depends on which connector is available and what permissions have been granted.

This should not be confused with unrestricted access to every file in every connected account. Users still need to connect the relevant application, and availability depends on the connector and plan.

## Monthly Recap is now out of beta

Claude's Monthly Recap, called Reflect in Settings, is now generally available beyond its earlier beta status for Free, Pro, Max and Ultra users on the web, Claude Desktop and mobile apps.

Anthropic says recaps can now include activity from Claude Code sessions and cloud Cowork tasks. Users can also delete stored recaps from the page.

This makes the recap broader than a simple summary of chat conversations. It can include work carried out in coding and cloud task environments, giving users a wider view of how they have been using Claude.

The recap remains a summary of activity, not an independent assessment of the quality or business value of that work.

## Why these changes matter

The three updates address different parts of the same user problem.

**Artifacts address reuse.** A tool created in a conversation can become a desktop app that is easier to open again.

**File transfers address workflow movement.** A user can move files between Claude and connected applications without treating every connector as read-only.

**Monthly Recap addresses continuity.** Work across chat, Claude Code and cloud Cowork can be reflected in one recap.

The direction is clear: AI assistants are trying to become working environments, not just places to ask questions.

For businesses, the distinction matters. A chatbot answers a request. A connected assistant can create an output, move it into another application and help the user continue the task there. The value depends on permissions, reliability and whether the workflow saves meaningful time.

## What teams should check before using these features

1. **Review installed Artifacts.** Check what an Artifact does and what operating-system access it requests before installing it as an app.
2. **Check connector permissions.** Connect only the services needed for the workflow and understand what file actions the connector supports.
3. **Set organisation controls.** Team and Enterprise owners should review whether file transfer features are enabled and appropriate for their data policies.
4. **Treat generated files as work products.** Review content, formulas, access permissions and confidential information before sharing or saving a file elsewhere.
5. **Check Monthly Recap settings.** Understand what activity is included and use the available deletion control if a stored recap is no longer wanted.
6. **Measure time saved.** Compare the full workflow before and after the feature, including review and correction time.

A useful business metric is *workflow completion time*: the time from starting a task to having an approved file or working tool in its final destination. Measure that, rather than counting how many files or Artifacts Claude creates.

## Frequently asked questions

### Can Claude Artifacts be installed as desktop apps?

Yes. Anthropic says users can install an Artifact as an app on Mac or Windows. It gets its own window and icon. The feature is currently in beta.

### Can an installed Claude Artifact interact with my computer?

Anthropic says an installed Artifact can interact with the operating system in ways other apps might. Users should review what the specific Artifact does before installing or using it.

### Can Claude send files to connected apps?

Yes. Anthropic is gradually rolling out file transfers in beta. Claude can send a file to a connected app or save a file that the app offers, subject to connector support and permissions.

### Which Claude plans get file transfers?

Anthropic lists Pro, Max and Ultra plans, and Team and Enterprise plans when an owner enables the feature. The rollout is gradual.

### What changed in Claude Monthly Recap?

Monthly Recap is out of beta for Free, Pro, Max and Ultra users on web, desktop and mobile. Recaps can include Claude Code sessions and cloud Cowork tasks, and users can delete stored recaps.

### Is this the same as Claude Computer Use?

No. Installing an Artifact as an app, transferring files through connectors and Computer Use are separate capabilities. Anthropic's release notes list Computer Use beta for Team and Enterprise from November 20, while the November 24 update covers Artifacts, file transfers and Monthly Recap.

## Claude is becoming a place to do the work

The latest update is not a new frontier model announcement. It is a set of product changes that make Claude outputs easier to reuse and move between applications.

That may be more important to everyday users than another benchmark result. The next stage of AI competition will be shaped not only by model quality, but also by how well an assistant fits into the software people already use.
