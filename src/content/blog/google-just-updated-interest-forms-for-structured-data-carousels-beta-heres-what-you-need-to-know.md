Hey folks,  
Nita here, I'm back with a quick-but-crucial update that anyone in SEO, especially technical SEO, should have on their radar.

So, Google just made a quiet little update on **April 11** that you might've missed — but trust me, it’s one of those updates that’s going to matter if you’re experimenting with **structured data carousels (beta)**. Here's the lowdown in plain speak.

### What's the Update?

Google has updated the documentation for the Structured Data Carousels (Beta) to list the currently available interest forms and clarify the supported query types and regions.

In simple terms:  
They’re making it easier for us (publishers, SEOs, devs) to understand **how to express interest** in participating in this feature _and_ what kind of search queries it currently supports.

![](https://rudrakasturi.wpcomstaging.com/wp-content/uploads/2025/04/image-23.png)

### Why Does This Matter?

Because this is Google’s way of nudging us:

> **_"Hey, this is still in beta — but if you’re serious about showing up in these new carousel formats, here’s how you get involved."_**

For those of you running product listings, event sites, recipes, or any kind of structured-rich experience, **this is a way to get ahead** before the feature becomes mainstream.

Think of this like early access to a new game mode in SEO — fewer players, more visibility.

### What Are Structured Data Carousels (Beta)?

Quick refresher:  
These carousels are a new way for Google to display structured content directly in search results. We're talking about horizontally swipeable carousels showing products, events, deals, or content — **driven entirely by structured data** on your site.

It’s like rich snippets on steroids.

### So, What's Actually Changed?

Here's what Google updated:

*   **Current Interest Forms**: They've updated the process for expressing interest in the beta. If you want in, you’ve got to fill out the latest form. The old ones? Probably going to a black hole.
*   **Supported Query Types**: Google now documents exactly which search query types are currently being supported by the beta carousel format. This helps you align your content strategy better — especially if you’re testing for eligibility or visibility.

### What You Should Do (Like... Now)

1.  **Read the updated doc**  
    Link: [Structured Data Carousels (Beta) Documentation](https://developers.google.com/search/docs/appearance/structured-data/carousels-beta#feature-availability)  
    Skim it, get a sense of whether your content fits.
2.  **Submit the new interest form** (as mentioned below)  
    Don't assume you're in the beta if you submitted the old form months ago. Go fresh.
3.  **Audit your structured data**  
    Ensure your markup is bulletproof. Use Schema.org types that align with Google's examples. Use Search Console + Rich Results Test to debug.
4.  **Experiment with content types Google’s supporting**  
    Are you creating content that maps to those supported query types? If not, this is your window to pivot.

## Feature availability

This feature is in beta and you may see changes in requirements or guidelines, as we develop this feature. If your business is based in EEA, or serves users in EEA, and you would like to learn more and express interest in these new experiences, you can start by filling out the applicable form:

*   For queries related to ground transportation, hotels, vacation rentals, local business, and things to do (for example, events, tours, and activities), use this [Google Search aggregator features interest form](https://support.google.com/websearch/contact/search_dma)
*   For flights queries, use this [flight queries interest form](https://support.google.com/travel/contact/flight_queries_interest)
*   For shopping queries, get started with the [Comparison Shopping Services (CSS) program](https://support.google.com/css-center/answer/7524491)

This feature is currently only available in [European Economic Area](https://ec.europa.eu/eurostat/statistics-explained/index.php?title=Glossary:European_Economic_Area_\(EEA\)#:~:text=See%20EEA%20disambiguation%20page%20for,and%20Norway%3B%20excluding%20Switzerland\).) (EEA) countries, on both desktop and mobile devices. It's available for travel, local, and shopping queries.
