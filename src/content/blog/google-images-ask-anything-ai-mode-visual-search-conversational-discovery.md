Google Images is testing a feature that could change how people use saved images. An Ask Anything option in image collections allows users to take a group of saved images into AI Mode and ask a question about them together.

The feature was spotted in Google Images on November 22 and reported by Search Engine Roundtable on November 25. It is an observed feature, not a formal announcement that the experience is available to every user or in every country.

The distinction matters. A traditional image search helps a person find pictures. A conversational visual search experience can help the person compare, interpret and make decisions using several pictures as context.

## What is Google testing?

Users can save images in Google Images collections. The new Ask Anything action appears to let a user select a collection and ask AI Mode a question about the images as a group.

Instead of opening every image separately, the user can ask a broader question. The reported interface also labels information from saved items as preferred context in the AI Mode experience.

This is a small interface change with a potentially larger implication: saved images may become part of a continuing search conversation rather than a passive bookmark folder.

## Why this matters for visual search

Consider a person planning a kitchen renovation. They save images of different layouts, cabinet finishes, lighting and storage ideas. The next question is not necessarily another keyword search. It may be: which of these kitchens has the best storage for a narrow room, or which design uses lighter materials?

A similar journey happens in ecommerce. A shopper may save images of shoes, furniture, clothing or skincare packaging and then ask for comparisons. Visual search becomes a way to express preferences that are difficult to describe with words.

The AI system is not simply identifying an object in one picture. It is helping the user reason across a set of visual references.

## What should SEO teams do?

This observation is not a new Google ranking factor. It does not mean adding more images automatically improves rankings or that a particular image schema guarantees inclusion in AI Mode.

It does, however, reinforce the importance of making images useful and understandable.

1. Use original images that genuinely show the product, place, process or idea.
2. Write descriptive file names and alt text that explain the image accurately.
3. Place images near the relevant explanatory text.
4. Use high-resolution images with a clear subject and appropriate dimensions.
5. Ensure product images match the actual product, colour, model and availability.
6. Provide captions where the visual needs context.
7. Make image pages and surrounding HTML accessible to search crawlers.
8. Use structured data only where it accurately describes the visible page content.

For ecommerce teams, the product feed, product page, image and structured data should tell the same story. A mismatch between the image and the actual variant can damage user trust even if the page is discoverable.

## Google Images versus conversational image search

The direction is broader than one Google experiment. Microsoft has also been observed testing an Ask action on Bing image results, where users can move from a selected image into a Copilot question.

These are separate product observations, not evidence of a shared rollout or a common ranking system. But both point towards a similar interface direction: users can move from seeing an image to asking questions about it.

## The new image SEO question

For years, image SEO focused on helping search engines understand and index images. That remains important. The next question is whether an image can also help an AI system understand a user's visual intent.

A product image may need to communicate more than its subject. It may need enough surrounding information for a system to understand the product type, material, size, use case and differences between variants.

Publishers and retailers should not respond by stuffing alt text with keywords or publishing dozens of near-identical images. They should invest in accurate, original and context-rich visual content.

**The change to watch is not whether Google adds another AI button. It is whether visual collections become a new starting point for research, comparison and purchase decisions.**

*Editorial note: The Ask Anything feature was reported from an observed Google Images interface. Availability and rollout status may vary. Do not treat this report as confirmation of a global launch.*
