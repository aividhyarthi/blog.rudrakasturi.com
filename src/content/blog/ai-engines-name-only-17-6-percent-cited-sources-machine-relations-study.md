# AI Engines Name Only 17.6% of the Sources They Cite, Study Finds. Why Mentions and Citations Need Separate Metrics

An AI answer can cite a website without naming that publisher in the words it gives the user. That distinction is the focus of a November 2026 study by Machine Relations Research.

The study examined 7,098 source-and-answer pairs across 899 AI answers. It found that the answer text named the cited source in 17.6% of the pairs.

The finding matters because AI visibility reports often combine brand mentions and citations into one score, even though they describe different events.

## The study at a glance

| Measure | Reported result |
|---|---:|
| AI answers analysed | 899 |
| Testable source-and-answer pairs | 7,098 |
| Cited sources named in answer text | 17.6% |
| Question panel | 49 AI-visibility buying questions |
| Engines | ChatGPT, Gemini, Claude, Perplexity |
| Publication date | November 7, 2026 |
| Research publisher | Machine Relations Research |

The researchers define a named source as a cited domain whose brand name appears in the answer text, after applying their text-cleaning and matching rules.

## The differences between engines

The study reports substantial differences between the four API routes it measured.

| Engine | Cited sources named in answer text |
|---|---:|
| ChatGPT | 49.9% |
| Gemini | 17.1% |
| Claude | 13.1% |
| Perplexity | 8.0% |
| **All four** | **17.6%** |

The researchers also report that Perplexity cited more sources per answer on average in this panel, while naming fewer of those sources in the prose.

These figures should be read as results for the sampled routes and question set, not as permanent characteristics of the consumer products.

## Why a citation and a mention are different

Consider a hypothetical answer that says:

"Several tools can help companies monitor AI search visibility. The comparison below is based on published product documentation."

The answer might include a citation to a publisher's research page without naming the publisher in the sentence.

Now consider the opposite: an answer might mention a brand by name but cite a different website, or no page from that brand at all.

That creates two separate events:

| Event | Meaning |
|---|---|
| Brand mention | The answer text names the brand |
| Citation | The answer includes a source link |
| Named citation | The answer both cites the source and names it in the text |

A tracker that measures only mentions can miss citations. A tracker that measures only links can miss brand recommendations and names that appear without a link.

## What did the methodology include?

The research used 49 questions in the Index's AI-visibility category. The questions covered buying and comparison intents such as best tools, selection advice, product value and head-to-head comparisons.

The study reports 1,129 successful runs across 23 dates from August 7 to November 2, 2026. The final named-source analysis used 899 answers and 7,098 testable citation pairs after excluding categories of sources and question-source pairs that could distort name matching.

The engines were accessed through specified API routes, including GPT-4.1 mini and other model routes listed in the methodology.

## Important methodological caveats

The research page is unusually detailed about exclusions and matching rules. Those details matter when interpreting the percentages.

- The questions were about AI visibility tools and buying decisions, not a balanced sample of all search topics.
- The study used API routes, not necessarily the same interfaces or model versions every consumer sees.
- The source name was matched using domain-derived text rules.
- General platforms such as Google, YouTube and Reddit were excluded from the testable source-pair analysis.
- Only answers with stored citation lists were included in the denominator.

The results are therefore a useful measurement case study, not a universal rate for every AI response.

## How AEO reporting should change

A more complete AI visibility report should show at least four separate measures.

| Metric | Calculation | Interpretation |
|---|---|---|
| Mention rate | Answers naming the brand / answers tested | How often the brand appears in prose |
| Citation rate | Answers citing the domain / answers tested | How often the website is linked |
| Named citation rate | Cited pairs where source is named / testable cited pairs | How often a citation is explicitly named |
| Retrieval rate | Queries where the page is retrieved / queries tested | How often the page enters the candidate set |

These measures should be reported by engine, query type, country, language and observation date wherever the data allows.

## The practical implication

If a publisher wants to understand its AI visibility, it should not ask only, "Did ChatGPT mention our brand?"

It should also ask:

- Did the system retrieve our page?
- Did it cite our page?
- Did it name our brand?
- Did the cited page support the answer?
- Did the user click through?

Each question measures a different stage of visibility and user behaviour.
