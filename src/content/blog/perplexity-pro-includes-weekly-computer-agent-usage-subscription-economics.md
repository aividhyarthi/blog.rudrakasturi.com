Perplexity is changing what a paid AI subscription includes. Pro subscribers now receive a weekly allowance for Perplexity Computer, the company's agent platform that can carry out multi-step tasks.

Previously, Pro did not include Computer usage credits. The new allowance appears as a weekly meter under Settings, in Usage and credits. It shows how much included usage remains and when the meter resets.

The announcement matters beyond Perplexity. AI companies are beginning to package task execution alongside chat, search and model access. The commercial question is becoming how much work an agent can complete within a subscription, not just how many questions a user can ask.

## How the weekly Computer allowance works

Perplexity says each user's weekly period begins with their first Computer task and resets seven days later. Unused included usage does not carry over.

Computer uses the included Pro allowance first. If the meter runs out, it can use credits already in the account. If there are no credits and auto-refill is off, the task stops. Users can buy credits or wait for the weekly reset.

Auto-refill is off by default and remains under the user's control. Users can switch it on or off in Settings under Usage and credits.

The included allowance runs tasks on Light effort. Higher effort settings, from Light to Ultra, consume usage faster and become available when the account has credits.

Perplexity says the included usage is live on paid Pro plans. Promotional and non-paying Pro plans, Max and Enterprise retain their existing credit arrangements.

## What is Perplexity Computer?

Computer is an agent system designed to coordinate work across tools and services. Instead of simply answering a question, it can carry out a sequence of actions to complete a task.

That distinction is important. A chatbot may explain how to research a market. An agent can potentially gather information, organise findings, work with files and produce a deliverable. The exact work it can perform depends on its connected tools, permissions and effort setting.

## Why include agents in a subscription?

There are three possible commercial benefits.

First, it makes agent use easier to try. A Pro subscriber no longer has to buy a separate credit balance before using Computer.

Second, a weekly allowance gives Perplexity a predictable way to control infrastructure costs. Agent tasks can consume more compute than short text exchanges because they may involve several model calls, tool use and repeated reasoning.

Third, it creates a path from casual usage to paid consumption. People who need more work can purchase credits, while lighter users remain within the included allowance.

These are business-model implications, not claims about Perplexity's internal cost structure.

## What users should watch

- Check the weekly meter before starting a large task.
- Understand that unused usage does not roll over.
- Keep auto-refill off if you do not want additional credit purchases.
- Use Light effort for routine tasks and reserve higher effort for work that justifies the extra consumption.
- Review outputs before using them in business decisions.
- Do not give an agent access to sensitive files or accounts unless the task requires it and the permissions are understood.

## The bigger competition

AI subscriptions are likely to become more complicated as companies bundle search, chat, coding, research, browser use and task execution.

A flat monthly fee is easy to understand, but agent usage varies widely. One person may ask a few questions. Another may run a long research task involving multiple websites, documents and tools.

The weekly allowance is one way to balance predictable subscription pricing with variable compute demand.

**The next AI subscription comparison may not be about which model answers best. It may be about which service lets users complete the most useful work within the price they pay.**
